# System Architecture

## 1. Overview

RecruitHub follows a modular architecture. The platform is divided
into independent modules, with each module responsible for a specific
business domain, such as authentication, users, companies, jobs,
applications, resumes, interviews, notifications, and AI services.

Each module should encapsulate its own business logic and expose only
the functionality required by other modules.

This separation of responsibilities helps reduce coupling, improve
maintainability, simplify testing, and allow individual modules to
evolve without unnecessarily affecting unrelated parts of the system.
